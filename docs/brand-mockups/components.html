Tooltip

One bubble (.lf-tooltip) for everything Bootstrap tooltips did — Bootstrap is dropped on port. Used by the conditions ⓘ cue explainers, the one-time nudge and the slider hint (product nudges reuse the bubble; their show/dismiss timing stays app JS). Tap-to-reveal via the native Popover API (light-dismiss + Escape — the nav-menu precedent), not hover: the copy is load-bearing on mobile. Plain title attributes remain the free desktop nicety. Placement is lf-popover-anchor.js (all browsers, once in the layout on port): centred over the trigger, clamped inside the viewport — a bubble centred on an edge-hugging ⓘ would hang off-screen on phones — with the caret sliding to stay pointing at the trigger. No wiring per instance beyond popovertarget — app-opened bubbles (nudges, popover="manual" so the app owns dismissal) name their trigger with data-anchor instead and are positioned identically; see the live nudge on conditions.html. The script is also the nav menu's Safari/Firefox positioning fallback. The specimen is live — tap the ⓘ.

Text links

Forest link on charcoal body copy is a hue-only difference, so links in prose carry an underline as well — the cue that survives colour blindness. Opt in with .prose on the copy container; card bodies get it automatically through their <p>s (.lf-info-card__body p a), which leaves the legal Contents list and any button in a card body undecorated. Structural links — nav, cards, breadcrumbs, buttons — stay colour-only.
